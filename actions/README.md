# Actions

Add each action in its own directory, with an `action.yml` manifest at that
directory's root. For example, `actions/build-firmware/action.yml` is
referenced as `robin-thoni/esphome-actions/actions/build-firmware@<ref>`.

Keep each action's implementation, tests, and README alongside its manifest.
The repository root README is the catalog of reusable workflows and general
repository guidance.
